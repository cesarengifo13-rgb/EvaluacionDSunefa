Sección III (Criterios de Desarrollo Teórico):

1. OLTP vs Data Warehouse: OLTP opera transacciones diarias rápidas en tiempo real usando esquemas normalizados (3FN) para evitar anomalías. El Data Warehouse (OLAP) consolida datos históricos de solo lectura usando modelos dimensionales menos normalizados para acelerar consultas analíticas masivas.

2. Ingeniería Inversa: Escaneo de una base de datos física existente para reconstruir su modelo lógico y relaciones. Es indispensable al heredar sistemas legados (legacy) sin documentación antes de migrar datos.
